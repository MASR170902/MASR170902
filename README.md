## Tentang Saya

Saya tertarik pada sistem yang bekerja di dunia nyata, mulai dari perangkat IoT berbasis ESP32 yang terhubung lewat MQTT, sampai infrastruktur server yang berjalan di homelab sendiri. Saya suka mengotomasi hal-hal yang berulang, dan biasanya saya belajar paling banyak ketika sebuah sistem gagal lalu harus diperbaiki.

Saat ini fokus saya ada di pengembangan web dengan TypeScript, pengelolaan Linux dan Docker, serta memperdalam jaringan dengan MikroTik.
